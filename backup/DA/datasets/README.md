# Backup DA — Datasets

Datasets históricos usados en los webinars antiguos de DA (retail, Walmart, Taylor Swift, licores, experimentos A/B, BI, etc.).

## Subcarpetas

- [`data/`](./data/README.md) — Datos de países y transacciones, además de las subcarpetas `raw/` y `processed/`.
- [`dataset_andes_capital/`](./dataset_andes_capital/README.md) — Modelo estrella (dimensiones y hechos) de ventas de propiedades.
- [`dataset_sprint11_w35/`](./dataset_sprint11_w35/README.md) — Tablas de calendario, clientes, devoluciones, productos y ventas.
- [`duckdb/`](./duckdb/README.md) — Tablas de una librería (bookstore) en CSV y Parquet para practicar SQL con DuckDB.
- [`sp3/`](./sp3/README.md) — Proyectos comprimidos de SQL en VS Code (bookstore).
