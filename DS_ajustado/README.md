# DS ajustado

Versión revisada y reestructurada del programa de Data Science: notebooks tutor (`DS/`) y estudiante (`DS_students/`), imágenes, planes de clase (`Sprintplan/`), informes de auditoría e implementación, preguntas Kahoot y archivos de dependencias.

## Subcarpetas

- [`DS/`](./DS/README.md) — Notebooks completos (con soluciones) para el tutor, organizados por sprint.
- [`DS_students/`](./DS_students/README.md) — Versiones para estudiantes de los notebooks ajustados: sin outputs y con ejercicios en blanco.
- [`Images/`](./Images/README.md) — Imágenes y GIFs usados en los notebooks de DS.
- [`Sprintplan/`](./Sprintplan/README.md) — Planificación de cada clase (`sprintN-classM.md`) y el índice vigente de notebooks (`notebooks-index.md`).
